# Content Module

Blog posts, LinkedIn content, newsletters, and marketing materials. Topics derived from demand patterns.

## Key Files

- `topics.md` — maps demand evidence to content ideas (the bridge between PULL analyses and content planning)
- `style-guide.md` — voice, audience, distribution, rules
- `drafts/` — working content
- `published/` — archive of published pieces

## Conventions

- Every topic must reference at least one PULL analysis or demand pattern
- Use actual buyer language from PULL analyses, not marketing language
- Lead with the scenario, not the product
- When new PULL analyses reveal recurring questions, check if they map to existing topics or suggest new ones
